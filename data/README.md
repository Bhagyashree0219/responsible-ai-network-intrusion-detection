
# Network Intrusion Detection Dataset

## Purpose
This folder is intended for documenting datasets used to develop
and evaluate the network anomaly detection system.

## Dataset Status
Dataset selection and integration are still in progress.

## Data Requirements
The detection script expects a CSV file containing numeric
network traffic features.

## Responsible Data Use
- Use datasets that are authorized for research.
- Follow the dataset license and terms of use.
- Do not upload private network logs or sensitive information.
- Document the source and meaning of each feature.

## Results
Detection results will be documented after testing with a suitable dataset.
